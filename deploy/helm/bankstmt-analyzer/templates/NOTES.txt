{{- else if not .Values.storage.persistence.enabled }}

WARNING: the local storage backend is selected and persistence is off.

  Uploaded PDFs go to an emptyDir, which is private to each pod. The API
  stores the files and the worker reads them, so with separate Deployments
  the worker cannot see what the API wrote and every upload fails at the
  OCR step.

  Either set storage.backend=s3 and point it at an S3-compatible store,
  or set storage.persistence.enabled=true with a ReadWriteMany claim.
{{- end }}
